Build our NbS tool

The NbS Map Platform's Interactive Map is the tool most people will use. We start from SCENE's NbS tool and ask, for every step: what do we keep, what don't we need, and what do we wish it had, so that it works for the Philippines.

How it works

  • Keep it
  • Maybe
  • We don't need it
  • We wish it had…

Each table builds the tool for one person (below). For every card, the table asks: would our person use this? Each step lets a table keep only about half of its cards, so keeping means choosing. Maybe is for cards the table is unsure about: it doesn't count either way. Anything missing becomes a wish, with the information it would need and who has it. At the end, each table has five dots for the cards and wishes that matter most, and five more for the data the tool needs most.

Each card here has the same number as the paper card on your table. Click a picture to see it larger. To try SCENE's tool yourself, open nbstool-beta.scenecoalition.org/interactive-map.

Who we build for

Five people who will use or run the tool. They are made up, but their work is real: if yours is different, tell your table's host and build for someone like you.
